# Support

DragonForge Security Test Lab is a pre-release defensive testing framework and public portfolio repository candidate. It is not a commercial support service and it must not be used as authorization to test third-party systems.

For ordinary bugs, documentation problems, or feature ideas, use the repository's GitHub issue templates when issues are publicly available. Use synthetic data and sanitized evidence only.

Do not post credentials, tokens, keys, production vault material, personal data, sensitive exploit details, or evidence from systems you are not authorized to test. Vulnerabilities in DFSTL belong in the private process described in [SECURITY.md](SECURITY.md).

Unsolicited code contributions are not currently accepted; see [CONTRIBUTING.md](CONTRIBUTING.md).
