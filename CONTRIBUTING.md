# Contributing to DragonForge Security Test Lab

DragonForge Security Test Lab is source-visible for evaluation, portfolio review, security review, and reference, but it is not an open-source project.

## Current contribution policy

Unsolicited code contributions and pull requests are not currently accepted. Contributor licensing/assignment terms and a CLA policy have not yet been established, so please do not submit source code, patches, test corpora, artwork, or other copyrightable implementation material unless David James has explicitly invited that contribution and supplied the applicable written terms.

Issue reports, reproducible bug reports, and non-code feedback are welcome when the repository is public. Security-sensitive reports should follow `SECURITY.md` rather than being disclosed publicly.

Submitting an issue or other feedback does not grant a license to DragonForge source code or alter the rights described in `LICENSE`.

## Third-party material

Do not submit third-party source, assets, test corpora, documentation, or other material unless its origin and license are known and compatible with the project. Existing third-party components retain the rights and obligations of their own licenses.

This temporary policy should be revisited before the project begins accepting external code contributions.
